# Contribuer à BCN

Merci de contribuer à un projet concernant l’évaluation de mineurs. La prudence méthodologique et la protection des personnes priment sur la rapidité.

## Contributions utiles

- expertise professionnelle sur les tâches scolaires numériques ;
- méthodologie de mesure et psychométrie ;
- ergonomie et accessibilité ;
- développement et tests ;
- protection des données ;
- relecture en langage clair ;
- retours d’usage anonymisés et recueillis dans un cadre autorisé.

## Règles

1. Ouvrir une issue avant une modification importante.
2. Décrire le besoin et les effets attendus.
3. Ne jamais publier de donnée permettant d’identifier un jeune.
4. Ne pas présenter un score comme diagnostique ou normatif sans preuve documentée.
5. Ajouter ou mettre à jour les tests lorsque le code change.
6. Documenter toute modification d’une épreuve, car elle peut rompre la comparabilité des résultats.

## Données interdites dans le dépôt

- noms, initiales ou coordonnées de jeunes ;
- dates de naissance complètes ;
- dossiers scolaires ou médicaux ;
- rapports réels non anonymisés ;
- identifiants techniques ou secrets ;
- jeux de données collectés sans cadre documenté.

## Proposition d’une épreuve

Toute proposition doit préciser :

- capacité visée ;
- population et tranche d’âge ;
- consigne exacte ;
- matériel ;
- durée ;
- variables enregistrées ;
- règle de cotation ;
- aides autorisées ;
- facteurs de confusion ;
- risques d’accessibilité ;
- justification et références éventuelles.
