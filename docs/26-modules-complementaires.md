# Modules complémentaires proposés après le premier essai

**Date :** 21 octobre 2026  
**Statut :** proposition priorisée pour les prochains incréments

Le premier essai complet montre que les gestes élémentaires ne suffisent pas à représenter l’usage scolaire réel. Les modules suivants complètent le BCN sans produire de note globale.

## Priorité 1 — Frappe et édition avancées

- dictée de trois minutes avec voix locale fixe ;
- correction d’un texte comportant des erreurs ;
- sélection de mots et de paragraphes ;
- copier, couper, coller et annuler ;
- mise en forme simple : titre, gras et liste.

Mesures principales : mots par minute, mots corrects par minute, erreurs finales, corrections, réussites autonomes, aides et temps actif.

## Priorité 2 — Gestion des fichiers et dossiers

- créer un dossier ;
- retrouver un fichier ;
- renommer, déplacer et classer ;
- enregistrer au bon emplacement ;
- reconnaître les principaux types de fichiers.

Mesures principales : étapes autonomes, actions incorrectes, retours, aides, réussite finale et organisation retenue.

## Priorité 3 — Lecture et manipulation d’un document scolaire

- ouvrir un document ;
- utiliser le zoom et le défilement ;
- retrouver une information dans plusieurs pages ;
- compléter une zone demandée ;
- enregistrer puis retrouver la version modifiée.

Mesures principales : réussite par étape, erreurs de repérage, autonomie, aides et incidents.

## Priorité 4 — Production scolaire intégrée

- recopier une consigne ;
- rédiger une réponse courte ;
- insérer une image fournie ;
- ajouter un titre ;
- enregistrer le travail dans un dossier indiqué.

Ce module rassemble plusieurs capacités dans une situation fonctionnelle. Le bilan sépare chaque étape au lieu de créer une note unique.

## Priorité 5 — Navigation web et recherche d’information

- reconnaître la barre d’adresse ;
- suivre un lien ;
- revenir à la page précédente ;
- retrouver une information précise ;
- distinguer résultat, publicité et téléchargement.

Les pages sont simulées et intégrées localement afin qu’aucune donnée de passation ne soit envoyée sur Internet.

## Priorité 6 — Outils d’adaptation

- agrandissement et contraste ;
- lecture vocale ;
- dictée vocale simulée ou locale ;
- prédiction de mots ;
- comparaison sans adaptation puis avec adaptation.

Les résultats adaptés restent séparés et leur comparabilité est explicitement indiquée.

## Modules secondaires possibles

- raccourcis clavier essentiels ;
- utilisation d’un tableau ou formulaire ;
- partage d’un document dans une interface simulée ;
- sécurité numérique élémentaire ;
- prise en main d’un appareil tactile ;
- fatigue, confort et préférence de dispositif.

## Éléments désormais intégrés dans la version 0.3

- repérage des icônes Windows ;
- repérage des icônes de traitement de texte ;
- repérage des actions générales sur les fichiers ;
- simulation de deux fenêtres ;
- raccourcis tout sélectionner, copier, coller, couper, annuler et rétablir.

## Ordre recommandé

1. dictée et manipulation de texte ;
2. fichiers et dossiers ;
3. document scolaire ;
4. production scolaire intégrée ;
5. navigation web locale ;
6. comparaison avec outils d’adaptation.
