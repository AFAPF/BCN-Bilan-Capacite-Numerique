# Protocole progressif de validation

## Vocabulaire contrôlé

- **En conception** : contenu encore modifiable.
- **Standardisé** : consignes, matériel et cotation définis et reproductibles.
- **En cours de validation** : études méthodologiques commencées mais preuves incomplètes.
- **Étalonné** : distributions de référence établies sur une population définie.
- **Normé** : terme utilisable uniquement si les normes et leurs limites sont documentées et validées.

## Phase 1 — Validité de contenu

- définir chaque construit ;
- documenter le lien entre construit, tâche et mesure ;
- solliciter plusieurs catégories de professionnels ;
- recueillir l’avis de jeunes concernés ;
- vérifier pertinence, exhaustivité et compréhension.

Livrable : matrice construits–épreuves–variables–interprétations.

## Phase 2 — Standardisation

Pour chaque épreuve :

- consigne verbatim ;
- exemple et entraînement ;
- matériel et configuration ;
- durée et chronométrage ;
- aides permises ;
- critères d’arrêt et de reprise ;
- règles de codage des erreurs ;
- calcul exact des indicateurs ;
- incidents à documenter.

Livrable : manuel de passation versionné.

## Phase 3 — Étude pilote

Objectifs :

- vérifier compréhension et faisabilité ;
- repérer les effets plancher et plafond ;
- détecter les problèmes techniques ;
- estimer la durée et la fatigue ;
- améliorer les tâches avant l’étalonnage.

Le pilote doit inclure des âges, profils, matériels et professionnels variés. Son effectif ne constitue pas automatiquement un échantillon normatif.

## Phase 4 — Propriétés de mesure

À étudier selon la pertinence :

- reproductibilité test-retest ;
- accord inter-évaluateurs ;
- cohérence des mesures ;
- validité de construit ;
- validité critériée lorsqu’un comparateur défendable existe ;
- sensibilité au changement ;
- erreur de mesure ;
- influence du matériel, de l’entraînement et du contexte.

Les analyses seront définies avant l’examen des résultats lorsque cela est possible.

## Phase 5 — Étalonnage

- définir la population de référence ;
- calculer l’effectif requis ;
- documenter le recrutement et les exclusions ;
- contrôler la représentativité ;
- établir distributions, percentiles et intervalles d’incertitude ;
- rechercher les facteurs justifiant des groupes distincts ;
- prévoir une validation externe.

Aucun seuil clinique ne sera créé à partir d’un simple choix visuel dans les données.

## Phase 6 — Surveillance

- versionner les épreuves et normes ;
- enregistrer les changements susceptibles d’affecter les scores ;
- surveiller incidents et biais ;
- réexaminer périodiquement les normes ;
- publier les limites et corrections.

## Données des mineurs

Avant toute collecte réelle : préciser la base légale, l’information des jeunes et représentants légaux, les accords requis, les droits d’accès et d’effacement, la durée de conservation, la sécurité, le rôle des partenaires et la nécessité éventuelle d’une analyse d’impact.
